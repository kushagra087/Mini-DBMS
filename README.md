Mini Text Database Application

A lightweight text-based database management system built in Python. This project allows users to store, retrieve, update, delete, and search records using simple file operations without requiring a traditional database like MySQL or SQLite.

Features

  Add new records
  View all stored records
  Search records by keyword or ID
  Update existing records
  Delete records
  Persistent data storage using text files
  Simple command-line interface
  Beginner-friendly Python project
  
Technologies Used

  Python 3.x
  File Handling
  Object-Oriented Programming (Optional)
  Command Line Interface (CLI)
